# 嵌入式练习仓库

电子信息工程专业，目标：把思考能力和动手能力练到嵌入式岗位的企业要求。

## 练习路线（对照岗位要求）

- C / C++ 基础与代码规范
- 至少一块单片机平台的完整项目（个人项目同样算数）
- 常用外设驱动：UART / I2C / SPI / ADC / CAN
- RTOS 基础：FreeRTOS / RT-Thread，任务调度、中断、内存管理
- 调试工具：示波器、逻辑分析仪、万用表、JTAG / SWD
- 读英文芯片手册和原理图，写设计与测试文档

## 第一个项目：单片机环境监测

目标：读传感器手册 → 接线 → 写 I2C 驱动 → 串口输出数据 → 用逻辑分析仪/调试器验证 → 写测试记录。

步骤清单：

- [ ] 确定开发板型号（待补充）
- [ ] 读传感器数据手册，整理寄存器和时序要点
- [ ] 按原理图接线，拍照留档
- [ ] 写 I2C 驱动骨架，读到设备 ID
- [ ] 串口输出温湿度/气压等原始数据
- [ ] 逻辑分析仪抓波形，确认时序无误
- [ ] 按下方模板补一份测试记录

## 思考能力怎么练

- 每次先写清楚：现象是什么、可能原因有哪几条、怎么逐条排除
- 出了 Bug 先定位再改，不靠试错碰运气
- 每个项目结束补一段复盘：卡在哪、怎么解决的、下次怎么更快
